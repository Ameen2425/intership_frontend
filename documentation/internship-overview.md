## 3. Technology Stack & Design System

The showcase is constructed without third-party JavaScript frameworks like React or Vue, strictly utilizing vanilla modern web standards and professional tooling:

| Category | Primary Technologies | Role in Project |
| :--- | :--- | :--- |
| **Markup** | HTML5 Semantic Standards | Accessible document blueprints, WAI-ARIA roles, native disclosure widgets |
| **Styling** | Modern CSS3 & Media Queries | Flexbox, CSS Grid, custom properties, responsive reflow, zero overflow |
| **Scripting** | JavaScript (ES6+) | DOM Manipulation, async/await, Fetch API, live regex validation, contrast checks |
| **Frameworks** | Bootstrap 5.3.3 | Responsive 12-column grid, navbar, modals, accordions, tabs, toasts |
| **Preprocessing**| Dart Sass (SCSS) | Modular partials, parametric mixins, mathematical functions, compile watcher |
| **REST Data** | JSONPlaceholder API | Asynchronous post stream, author filtering, reader discussion threads |

## 4. Key Learning Outcomes

1. **Semantic Web Architecture:** Writing accessible, SEO-optimized markup that assistive screen readers can interpret natively without redundant non-semantic wrappers.
2. **Deep Specificity Comprehension:** Navigating the CSS Cascade from inline declarations `(1,0,0,0)` to classes `(0,0,1,0)` and element tags `(0,0,0,1)`.
3. **Cross-Device Responsiveness:** Crafting liquid viewports across Mobile (<576px), Tablet (576px–768px), Laptop (769px–1024px), and Desktop (>1024px) with zero horizontal scroll bleed.
4. **Resilient Asynchronous Programming:** Managing network promises, try/catch recovery, latency measurement, pagination, and skeleton loading states.
5. **Human-Centered Form Validation:** Providing instant, accessible, non-punitive feedback with live password entropy calculation and accessible WAI-ARIA error alerts.
6. **Design System Scaling with Sass:** Organizing production stylesheets into modular partials (`_variables.scss`, `_mixins.scss`, `_components.scss`) with compilation automation via Node.js and Dart Sass.
