## 🌟 Project Overview

This repository represents the completed **Front-End Development Internship Project** assigned by **Cognifyz Technologies**. Rather than repeating generic AI dashboard templates or uniform SaaS components, each assignment has been crafted with its own distinct visual identity, tailored to its real-world purpose:

- **1 Master Developer Portfolio:** An editorial, human-centered project showcase presenting all eight tasks with custom visual previews, curriculum roadmaps, and direct links to code and explanations.
- **8 Dedicated Task Implementations:** Every assignment is completely self-contained in its own directory with dedicated explanation documentation, live demonstration code, and independent visual styles.
- **Pure Web Standards Foundation:** Built strictly using vanilla HTML5, CSS3, JavaScript (ES6+), Bootstrap 5, Dart Sass, and REST APIs without third-party JS frameworks (such as React or Vue).

## 📋 The 8 Internship Tasks At a Glance

| Task | Level | Design Direction | Technical Highlights |
| :---: | :---: | :--- | :--- |
| **01** | Level 1 (Beginner) | **Editorial / Informational Document** | Semantic HTML5 structure, H1&ndash;H6 hierarchy, data tables with `thead`/`tbody`/`tfoot`, figures with captions, and native `details`/`summary` disclosures without JavaScript. |
| **02** | Level 1 (Beginner) | **Creative CSS Playground** | 100% inline CSS styling (`style=""`), typography specimens, surface fills, linear gradients, box model geometry, and side-by-side unstyled vs. styled comparison. |
| **03** | Level 2 (Intermediate) | **Lifestyle &amp; Travel Journal** | Real-world publication layout, 4 responsive tiers (Mobile, Tablet, Laptop, Desktop), zero horizontal overflow, pure CSS mobile drawer, and adaptive itinerary table. |
| **04** | Level 2 (Intermediate) | **Interactive Color Playground** | Minimal distraction-free canvas, random hex generator, tactile swatch buttons, native color picker, luminance contrast adaptation, and instant reset action. |

## 🚀 How to Run the Project Locally

No database or build setup is required to run the project. You can serve it using Python or Node.js:

### Option 1: Using Python (Instant, No Setup Required)
```bash
# Navigate to the project directory
cd Cognifyz_Frontend_Internship

# Launch static server on port 3000
python -m http.server 3000
```
Open your browser and navigate to: **`http://localhost:3000`**

### Option 2: Using Node / NPM
```bash
# Start local server
npm start
```

## 🎨 How to Compile and Watch Sass

The project uses modern **Dart Sass**. Compilation scripts are configured in `package.json`:

```bash
# Compile SCSS partials to expanded CSS with source maps:
npm run build:sass

# Compile minified production CSS:
npm run build:sass:min

# Start live file watcher for active SCSS development:
npm run watch:sass
```

The pre-compiled `css/styles.css` file is included out-of-the-box so the project renders immediately without running a build command.
