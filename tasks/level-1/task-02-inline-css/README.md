## Task Overview
This project demonstrates the direct application of CSS declarations to HTML elements using the `style` attribute. It showcases how font size, font color, background gradients, flexbox layouts, borders, and shadows are styled purely inline without external or embedded stylesheets.

## Technologies Used
- HTML5
- Inline CSS3 Declarations (`color`, `font-size`, `background`, `border-radius`, `box-shadow`, `display: flex`)

## Key Features Implemented
1. **Font Color & Size Transformations:** Multiple examples varying sizes, weights, and color formats (hex, rgba).
2. **Backgrounds & Gradients:** Demonstrating solid fills, RGBA transparency, and linear gradients.
3. **Comparative Demonstration:** Side-by-side contrast between an unstyled default browser element and an inline-styled card.
4. **CSS Specificity Breakdown:** Visual explanation of why inline styles hold a `(1, 0, 0, 0)` specificity weight.

## Files
- `index.html` - Evaluator & Task Explanation page with live demonstration.
- `demo.html` - Standalone pure inline CSS implementation.

## How to Test
1. Open `index.html` to review the task documentation and live demo.
2. Click **"Open Standalone Demo ↗"** (or open `demo.html` directly) to examine the standalone implementation.
3. Inspect DOM elements in Developer Tools (`F12`) to confirm that all styles originate from `style` attributes.
