Technical Terminology (Definition List)

Semantic HTML
The practice of using HTML tags that accurately convey their meaning and structural purpose to browsers, developers, and assistive devices.
Document Object Model (DOM)
A tree-structured representation of an HTML document that exposes its nodes to JavaScript for dynamic manipulation.
Accessibility (a11y)
Design and development principles ensuring digital content is usable by everyone, including people relying on assistive technologies.
