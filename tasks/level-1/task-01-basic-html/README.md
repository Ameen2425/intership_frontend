## Task Overview
This assignment demonstrates foundational HTML5 document structuring using semantic elements. The page provides an informational overview of Cognifyz Technologies, its core capabilities in Data Science and AI, and the 4-tier internship roadmap.

## Technologies Used
- HTML5 Living Standard
- Semantic Elements (`header`, `nav`, `main`, `section`, `article`, `figure`, `figcaption`, `footer`)
- Native interactive disclosure tags (`details`, `summary`)

## Key Features Implemented
1. **Semantic Blueprint:** Structured content using purpose-driven HTML5 tags instead of non-semantic containers.
2. **Heading Outline (H1–H6):** Hierarchical document flow supporting screen readers and search engines.
3. **Tabular Data:** Formatted schedule table with `caption`, `thead`, `tbody`, `tfoot`, and `scope` attributes.
4. **Interactive Disclosures:** Native collapsible FAQ elements requiring zero JavaScript.

## Files
- `index.html` - Professional Evaluator & Task Explanation page with live demonstration.
- `demo.html` - Standalone pure HTML5 implementation.
