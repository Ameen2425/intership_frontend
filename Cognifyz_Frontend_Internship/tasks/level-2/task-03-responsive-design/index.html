Task 03 — Fluid Responsive Design & Media Queries

Building cross-device layouts with external CSS media queries, CSS Grid, Flexbox, and zero horizontal overflow.

Section 1

Task Objective & Overview

Official Task Objective: Create a responsive webpage using an external styles.css file, implementing CSS media queries for mobile, tablet, laptop, and desktop screen sizes, testing layouts, and avoiding horizontal overflow.

What this task is about: Web users access digital products from vastly different screen resolutions — ranging from small smartphones (360px) to ultra-wide desktop monitors (1920px+). Responsive design ensures that layouts automatically reflow, adjust typography, collapse navigation bars, and restack multi-column grids smoothly without requiring separate websites.

Why this task is important: In professional frontend engineering, responsive design is mandatory. Mobile traffic represents the majority of global web consumption. A website that clips content, displays an unwanted horizontal scrollbar, or provides unclickable tap targets creates severe usability degradation and suffers in search engine rankings.

Section 2

Technologies Used & Key Concepts

External CSS3 (styles.css) CSS Media Queries (@media) CSS Grid (repeat, 1fr) Flexbox Alignment Fluid Units (clamp, %, vw) Zero Overflow (overflow-x: hidden)
  • 4-Tier Breakpoints: Mobile (< 576px), Tablet (576px – 768px), Laptop (769px – 1024px), and Desktop (> 1024px).
  • Pure CSS Hamburger Drawer: An accessible checkbox hack (input[type="checkbox"] + label) that expands and collapses mobile navigation without any JavaScript dependencies.
  • Adaptive CSS Grid Matrix: Reordering feature cards from 4 columns on desktop, to 2 columns on tablet/laptop, down to a single-column stack on mobile.
  • Responsive Table Protection: An overflow-x wrapper preventing wide tabular data from distorting the mobile viewport.
  • Real-time Breakpoint Badge: A dynamic floating badge powered via CSS pseudo-elements (::before) displaying the currently active media query tier.
Section 3

How the Implementation Works

The task structure links demo.html directly to styles.css. The CSS architecture establishes mobile-friendly baseline values and applies progressive media queries:

  • @media (max-width: 1024px): Laptop adjustments; collapses 4-column card grid into a 2-column layout.
  • @media (max-width: 768px): Tablet adjustments; switches desktop navigation links into a collapsible slide-down drawer triggered by the hamburger icon.
  • @media (max-width: 575.98px): Mobile adjustments; collapses grids into a single vertical column, scales down button widths to 100%, and refines heading typography using clamp().
  • overflow-x: hidden on html and body ensures zero horizontal scrolling at any viewport width.
Section 4

Code Walkthrough & Key Snippets

Below are the essential media query rules and layout declarations from styles.css.

1. CSS Grid Multi-Device Column Reordering:

styles.css (Grid Columns & Breakpoints) CSS3 
/* Desktop default: 4 Columns */
.responsive-card-grid {
  display: grid;
  grid-template-columns: repeat(4, 1fr);
  gap: 16px;
}

/* Laptop breakpoint: 2 Columns */
@media (max-width: 1024px) {
  .responsive-card-grid {
    grid-template-columns: repeat(2, 1fr);
  }
}

/* Mobile breakpoint: 1 Column */
@media (max-width: 575.98px) {
  .responsive-card-grid {
    grid-template-columns: 1fr;
  }
}

This cleanly manages the grid's column track sizing across desktop, laptop, and mobile devices without duplicated markup.

2. Pure CSS Mobile Hamburger Menu Toggle:

styles.css (CSS-Only Drawer) CSS3 
@media (max-width: 768px) {
  .nav-toggle-label { display: flex; }
  .nav-menu {
    display: none;
    position: absolute;
    top: 100%;
    left: 0;
    right: 0;
  }
  /* When checkbox is checked, display the navigation drawer */
  .nav-toggle-checkbox:checked ~ .nav-menu {
    display: flex;
  }
}

Leverages the sibling selector (~) with a hidden checkbox to build an accessible mobile drawer requiring zero JavaScript.

Section 6

Testing Guide & Expected Output

Expected Output: A fluid webpage reflowing effortlessly across all screen sizes, with a collapsible mobile menu, adaptive card matrix, and zero horizontal overflow.

  1. Open Standalone Demo: Click "Open Standalone Demo ↗".
  2. Activate DevTools Responsive Mode: Press Ctrl + Shift + M in Chrome/Edge/Firefox.
  3. Test Breakpoint Badges: Drag the width slider from 320px to 1200px:
    • < 576px: Badge shows "Mobile XS" and cards stack in 1 column.
    • 576px - 768px: Badge shows "Tablet MD" and cards reorder into 2 columns.
    • 769px - 1024px: Badge shows "Laptop LG".
    • > 1024px: Badge shows "Desktop XL" with 4 columns.
  4. Test Mobile Drawer: At < 768px, tap the hamburger icon to expand and collapse navigation links.
  5. Verify No Horizontal Scroll: Confirm there is no horizontal scrollbar at any screen width.
