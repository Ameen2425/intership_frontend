Task 04 — Interactive Button & Dynamic State

Handling DOM click events, dynamic background manipulation, luminance contrast evaluation, and runtime state management using JavaScript ES6+.

Section 1

Task Objective & Overview

Official Task Objective: Create an interactive webpage with a button, using JavaScript to change the page background color when clicked, adding multiple color options, displaying the selected color, providing a reset button, and ensuring smooth transitions.

What this task is about: Static websites display content, while interactive applications react to user gestures. This assignment bridges HTML and JavaScript by attaching event listeners to user controls, generating dynamic hexadecimal color values, and updating inline styles on the document body in real time.

Why this task is important: Event handling (addEventListener) and DOM manipulation are core competencies of modern frontend engineering. Understanding how client-side state is stored, mutated, and reflected on screen forms the direct foundation for state-driven libraries and real-time user experiences.

Section 2

Technologies Used & Key Concepts

JavaScript (ES6+) Event Handling (click, input) DOM Style Mutation Hex & RGB Color Math Luminance Contrast Algorithm Clipboard API CSS Transitions
  • Random Hex Generator: Mathematical string generator synthesizing random 24-bit hexadecimal color codes.
  • Curated Swatches & Native Picker: Allowing the user to select predefined brand palettes or choose custom colors via <input type="color">.
  • Live Perceived Luminance Algorithm: Using the ITU-R BT.601 formula (0.299*R + 0.587*G + 0.114*B) to automatically toggle dark or light text so the UI remains accessible on all backgrounds.
  • One-Click Clipboard Copy: Copying hex codes directly to system memory using navigator.clipboard.writeText with toast feedback.
  • Session History Stack: Maintaining an array of recent color selections that can be clicked to restore previous themes.
  • Reset Action: Restoring the original Cognifyz default navy theme (#0A0F1D) with smooth CSS transition easing.
Section 3

How the Implementation Works

When a user triggers an action (such as clicking "Generate Random Color" or clicking a preset swatch):

  1. JavaScript captures the desired hex code and applies it to pageBody.style.backgroundColor.
  2. The hex code is converted to red, green, and blue integer channels via bitwise shift operations in hexToRgb().
  3. The perceived luminance is calculated. If the brightness score exceeds 140, the .light-theme class is added to document.body, flipping text to dark slate. Otherwise, the class is removed.
  4. The monitor UI updates the HEX code, RGB format, and contrast indicator.
  5. The color is prepended to the colorHistory array and rendered as a clickable pill button.
Section 4

Code Walkthrough & Key Snippets

Below are the essential JavaScript functions from script.js driving the interactive color controller.

1. Generating Random Hex & Applying Color:

script.js (State Mutation) JavaScript ES6+ 
function generateRandomHex() {
  const chars = '0123456789ABCDEF';
  let color = '#';
  for (let i = 0; i < 6; i++) {
    color += chars[Math.floor(Math.random() * 16)];
  }
  return color;
}

function applyColor(hex, saveToHistory = true) {
  currentColor = hex.toUpperCase();
  pageBody.style.backgroundColor = currentColor;

  const { r, g, b } = hexToRgb(currentColor);
  activeSwatchPreview.style.backgroundColor = currentColor;
  hexCodeDisplay.textContent = currentColor;
  rgbCodeDisplay.textContent = `rgb(${r}, ${g}, ${b})`;
}

Directly alters the DOM body background and updates the visual swatch and text displays synchronously.

2. Accessibility & Contrast Adaptation:

script.js (Luminance Calculation) JavaScript ES6+ 
function calculateLuminance(r, g, b) {
  /* ITU-R BT.601 formula for perceived brightness */
  return 0.299 * r + 0.587 * g + 0.114 * b;
}

/* Toggle contrast class based on brightness threshold */
const brightness = calculateLuminance(r, g, b);
if (brightness > 140) {
  pageBody.classList.add('light-theme');
  contrastModeDisplay.textContent = 'Dark Text (Light BG)';
} else {
  pageBody.classList.remove('light-theme');
  contrastModeDisplay.textContent = 'Light Text (Dark BG)';
}

Ensures WCAG accessibility compliance by evaluating luminance so text never becomes illegible when bright backgrounds are applied.
