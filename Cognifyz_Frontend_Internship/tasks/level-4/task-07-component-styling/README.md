## Task Overview
This project demonstrates component-driven UI architecture using Bootstrap 5. It showcases how standard framework components (navbars, 12-column grid, responsive cards, modals, tabs, accordions, and toasts) are integrated and elevated into a custom dark SaaS theme via `styles.css`.

## Technologies Used
- Bootstrap 5.3.3 (via CDN)
- Bootstrap Icons (v1.11.3)
- HTML5
- Custom CSS Overrides (`styles.css`)

## Key Features Implemented
1. **Responsive Navbar:** Collapsible mobile toggler, dropdown menu, and action buttons.
2. **12-Column Responsive Grid:** Asymmetric grid layouts adapting across breakpoints.
3. **Interactive Modal Dialog:** Centered dialog with backdrop blur and focus trapping.
4. **Navigation Tabs:** Pill-based dynamic content pane switching.
5. **Collapsible Accordion:** FAQ disclosure component managed by Bootstrap JS.
6. **Live Toasts & Tooltips:** Push notifications and contextual hover popups.
7. **Custom Dark Theme Overrides:** Elevated styling using Cognifyz cyan and indigo gradients.

## Files
- `index.html` - Evaluator & Task Explanation page with live demonstration.
- `demo.html` - Standalone Bootstrap 5 implementation.
- `styles.css` - Custom CSS overrides for dark SaaS theme.
