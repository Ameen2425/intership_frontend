Task 01 — Basic HTML Page Architecture

Building a clean, accessible, and semantically structured informational webpage for Cognifyz Technologies using pure HTML5 standards.

Section 1

Task Objective & Overview

Official Task Objective: Create a complete index.html with correct HTML5 document structure, headings, paragraphs, images, tables, lists, native disclosure elements, and clear semantic landmarks.

What this task is about: This task focuses on understanding how content is organized on the web using semantic HTML5 tags. Instead of relying on generic <div> elements, the page uses purpose-driven elements like <header>, <nav>, <main>, <section>, <article>, <figure>, and <footer> to clearly define each structural role.

Why this task is important: Semantic markup is the bedrock of frontend development. It enables screen readers (assistive technologies for visually impaired users) to navigate documents logically, helps search engine crawlers index content accurately for SEO, and keeps the document tree clean and maintainable before any styling is applied.

Section 2

Technologies Used & Key Concepts

HTML5 Living Standard Semantic Landmarks Heading Outlines (H1-H6) Tabular Data (table, thead, tbody, tfoot) Native Disclosures (details, summary) WAI-ARIA Landmark Roles
  • Document Boilerplate: Proper <!DOCTYPE html> declaration, lang="en" attribute, UTF-8 charset, and mobile viewport meta tags.
  • Strict Heading Hierarchy: Logical outline from <h1> down to <h6> without skipping levels.
  • Rich Data Types: Ordered lists for linear steps, unordered lists for technical stacks, and description lists (<dl>, <dt>, <dd>) for terminology.
  • Tabular Architecture: Data tables structured with <caption>, <thead>, <tbody>, and <tfoot>, with explicit scope="col" and scope="row" headers.
  • Zero-JavaScript Interactivity: HTML5 <details> and <summary> elements delivering native accordion collapse functionality.
Section 3

How the Implementation Works

The implementation represents an informational overview of Cognifyz Technologies — detailing company operations in data science and AI, the 4-tier internship track, and web architecture foundations.

The document is structured into distinct landmark sections:

  • <header class="top-bar"> provides top branding and navigational links.
  • <main> wraps primary content, divided into modular <section> blocks each labeled by an internal heading.
  • <figure> encapsulates the Cognifyz logo with an associated <figcaption> for accessible illustration.
  • <table> cleanly maps out all 8 internship milestones and their completion statuses.
  • <footer> holds copyright information and the company motto.
Section 4

Code Walkthrough & Key Snippets

Below are the essential structural snippets from demo.html showing semantic elements in practical use.

1. Semantic Document Shell & Metadata:

demo.html (Document Boilerplate) HTML5 
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Task 01: Semantic HTML Page | Cognifyz Technologies</title>
</head>

Declares HTML5 mode, specifies UTF-8 encoding for universal characters, and defines responsive viewport scaling for mobile devices.

2. Tabular Data Representation:

demo.html (Structured Data Table) HTML5 
<table>
  <caption><strong>Cognifyz Frontend Internship Milestone Summary</strong></caption>
  <thead>
    <tr>
      <th scope="col">Task ID</th>
      <th scope="col">Level</th>
      <th scope="col">Status</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>Task 01</td>
      <td>Level 1</td>
      <td>Completed</td>
    </tr>
  </tbody>
</table>

The scope="col" attribute explicitly establishes a relationship between header cells and column data for assistive screen readers.

3. Native Disclosures:

demo.html (Native Interactive Details) HTML5 
<details open>
  <summary>What services does Cognifyz Technologies provide?</summary>
  <p>Cognifyz specializes in data science, AI, machine learning, and training.</p>
</details>

The <details> and <summary> tags provide built-in collapse/expand interactivity directly in the browser with zero JavaScript.
